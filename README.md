# Вместе — трекер семейных отношений 💞

Тёплый веб-трекер для пары (Мария и Даниил): кто что сделал по дому, свидания,
подарки, фильмы/книги, благодарности, статистика и достижения. Один проработанный
вариант в кремово-бежевой палитре.

Это «оживлённая» версия дизайн-прототипа из Claude Design: те же экраны и стиль,
но данные теперь хранятся в **Supabase** и сохраняются между сессиями.

## Разделы
- **Лента** — события по дням, фильтры по типу и человеку, лайки/благодарности
- **Календарь** — переключение месяцев, точки на днях, детали дня
- **Дела по дому** — задачи с «по очереди», чекбоксы, активные/сделанные
- **Свидания** — предложить / принять / отклонить
- **Статистика** — мягкий баланс участия, активность за 14 дней, по категориям
- **Достижения** — уровень пары и бейджи
- **Заметки** — записки-благодарности друг другу
- **Фильмы и книги** — коллекция с оценками

## Как это устроено
Статический сайт без сборки: React 18 + Babel Standalone (компиляция JSX в браузере),
Supabase JS — всё с CDN. Поэтому он работает на GitHub Pages как есть.

```
index.html          разметка + вся CSS (дизайн-система)
src/config.js       URL и публичный anon-ключ Supabase
src/data.jsx        типы активностей, метаданные пары, форматтеры дат
src/db.jsx          слой доступа к Supabase (маппинг row ↔ объект UI + CRUD)
src/ui.jsx          атомы интерфейса (Avatar, Modal, Icon, Stars, …)
src/screens.jsx     8 экранов
src/modals.jsx      детальные модалки и подтверждения
src/app.jsx         состояние, навигация, загрузка из БД, мутации
```

### База данных (Supabase)
Таблицы: `activities`, `tasks`, `date_ideas`, `notes`, `media`, `achievements`.
Имена колонок выбраны без зарезервированных слов SQL (`actor` вместо `by`,
`descr`/`when_text` вместо `desc`/`when`, `from_who` вместо `from`); `db.jsx`
маппит их обратно в объекты, которые ждут компоненты.

## Запуск локально
Из-за того, что Babel подгружает JSX-файлы по сети, открывать `file://` нельзя —
нужен локальный сервер:

```bash
cd vmeste
python3 -m http.server 8000
# открыть http://localhost:8000
```

## ⚠️ О приватности
Доступ к данным **открытый**: anon-ключ Supabase виден в `src/config.js`, а RLS-политики
разрешают чтение и запись роли `anon`. Это сознательный выбор для простого личного
сайта на два человека — но любой, у кого есть ссылка, может прочитать и изменить данные.
Если нужна настоящая защита, следующий шаг — включить Supabase Auth (вход по email)
и переписать RLS-политики на `auth.uid()`.
